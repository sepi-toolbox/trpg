# DB 시스템 구현 플랜

> 이 문서는 세션이 끊겨도 작업이 유실되지 않도록 진행 상태를 기록하는 기준 문서다.
> 새 세션은 이 문서를 먼저 읽고 "현재 단계"부터 이어서 작업한다.
> 규칙 원문은 별도 비공개 레포의 `DB_Rules_v2.pdf` (2쇄, 116p). 이 레포에는 원문을 넣지 않는다.

## 전제 (확정된 결정)

- 기존 SEPI TRPG 규칙을 **교체**한다. 레포·CI·Pages는 유지.
- **1인 조작** 캐릭터. 파티 확장이 가능한 구조로 설계하되 UI는 1인 기준.
- **옵션 룰 전부 구현 + config 토글** (`data/config.json`).
- 수치·계산식·판정 절차·규칙 표 → 원문 그대로 구현.
  이름·묘사·설정 텍스트 → 자체 작명(임시값). 원문 문장을 옮기지 않는다.
- 데이터(밸런스 수치, 이름, 묘사)는 성권이 JSON 테이블에서 직접 편집한다.
  → 스키마가 최우선 산출물. `docs/SCHEMA.md` 참고.

## 시스템 골격 요약 (규칙서에서 확정한 사항)

- 판정: **D20 하향** — 스킬 레벨 이하면 성공. 1 = 대성공(용), 20 = 대실패(마).
- 유리/불리(보온/베인): D20 2개 굴려 낮은/높은 쪽 채택. 복수면 개수만큼 추가. 상쇄됨.
- 능력치 6종(STR CON AGL INT WIL CHA) → 구간표로 기본치(base chance) 3~7.
  훈련 스킬은 기본치의 2배로 시작. 핵심 스킬 30종 + 비전계(마법 유파) 보조 스킬.
- 파생치: 이동력(종족 기반 + AGL 보정), HP = CON, WP = WIL, 피해 보너스(STR/AGL 구간표).
- 선제: 1~10 카드 무작위 분배. 대기(카드 교환) 가능. 리액션(패리/회피)은 자기 턴 소모.
- 전투: 명중 = 무기 스킬 판정. 패리(무기 내구도 초과 시 파손), 회피(EVADE).
  대성공 = 크리티컬(양자택일 효과), 대실패 = 사고표. 특수 공격(넘어뜨리기/무장해제/붙잡기 등).
- 피해: 무기 주사위 + 피해 보너스 − 방어구. 피해 유형 3종(참격/관통/타격)은 옵션 룰.
- 0 HP → 죽음 판정(CON, 3성공 회복 / 3실패 사망, 용=2성공 마=2실패). 중상표는 옵션 룰.
- 상태이상 6종: 능력치별 1:1 대응, 해당 능력치 판정에 베인. 푸쉬 굴림(옵션)의 대가.
- 휴식 3단계: 라운드(D6 WP) / 스트레치(D6 HP + D6 WP + 상태 1) / 시프트(전부 회복).
- 마법: 유파(보조 스킬) 판정. 위력 1~3 (WP 2/4/6), 트릭은 자동 성공 1 WP.
  요구 조건(주문/동작/매개체/재료), 금속 착용 시 시전 불가, 준비 주문 수 = INT 기본치.
  대실패 = 마법 사고표(D20). 몸에서 힘 끌어내기(주사위만큼 WP 획득+피해).
- 몬스터: 명중 굴림 없이 **자동 명중**하는 D6 공격표. 같은 공격 연속 불가(다음 항목으로).
  흉포도(Ferocity)만큼 선제 카드 = 라운드당 행동 수. 회피/패리는 기본 15 고정.
  크기 5단계, 저항(절반)/면역, 공포 공격. 플레이어의 특수 공격 대부분 무효.
- NPC: 미니언(스탯 축약, 0 HP 즉사) / 보스(WP·영웅 능력 보유). 미기재 스킬 기본치 5.
- 성장: 세션 종료 시 체크(용/마 굴림 + 질문 5개) → D20이 현재 레벨 초과하면 +1.
- 여정: 시프트 단위, 길찾기(BUSHCRAFT), 사고표(D12), 야영, 사냥/낚시/채집.

## 단계

각 단계의 완료 조건: 구현 + 테스트 통과 + **해석 질문 목록 제출** + 성권 승인 → 커밋.

의존성: 1 → 2 → 3 → 4 → (5, 6 병렬 가능) → 7 → 8 → 9 → 10 → 11.
기존 SEPI 코드(src/rules, src/game, src/data, src/ui)는 **10단계에서 제거**한다.
그 전까지는 빌드가 깨지지 않도록 공존시킨다 (새 시스템은 `src/system/` + `data/`).

## 작업 규칙

- 모든 무작위는 시드 RNG 경유. `Math.random()` 금지 (재현성 = 검증 가능성).
- 규칙 해석이 갈리는 지점은 임의로 정하지 않는다. 각 단계 끝에 질문 목록으로 제출.
  결정된 해석은 이 문서의 "해석 결정 기록"에 적는다.
- 옵션 룰은 전부 `config.json` 토글 뒤에 둔다. 토글 조합이 코어를 깨지 않는지 테스트.
- 커밋은 단계 단위. 커밋 메시지에 단계 번호 명시.

## 해석 결정 기록

- (0단계, ✅ 확정) 선제 카드가 부족하면 덱을 참가 턴 수만큼 확장(11, 12, …).
- (0단계) "STR" 사거리 무기(투척)의 사거리 = 시전자 STR 미터. "STR×2"도 동일 해석.
- (0단계) 몬스터 공격표에서 같은 눈이 연속으로 나오면 다음 항목, 6→1 순환. (원문 명시)
- (1단계) 대결 판정 동수는 능동측 승. 원문 "낮거나 **같으면** 성공" 명시 → 확정.
- (1단계, ✅ 확정) 푸쉬로 받은 상태이상은 그 재굴림 자체에는 베인을 주지 않는다.
- (1단계, ✅ 확정) 푸쉬는 판정당 1회.
- (1단계, ✅ 확정) 능력치 직접 판정에도 용/마 규칙 동일 적용.
  죽음 판정의 용=2성공/마=2실패 특례는 별도 처리(4단계).
- (2단계, ✅ 확정) 능력치 배치는 엔진이 강제하지 않는다 — "굴린 순서대로 배치 후
  2개 교환 가능" 원문 절차는 UI 단계에서 옵션으로 제공, 엔진은 배치 완료본만 검증.
- (2단계, ✅ 확정) 나이 보정의 하한을 3으로 클램프 (원문 미명시, 능력치 최솟값 3에 맞춤).
- (2단계, ✅ 확정) 생성 직후 알고 있는 주문을 준비 한도까지 자동 준비.
- (2단계, ✅ 확정) 스승 훈련의 "스킬당 1레벨 제한"은 세션 상태(호출부) 책임으로 이관.
- (3단계, ✅ 확정) 선제 카드: 참가 턴 수가 10을 넘으면 덱을 11, 12…로 확장.
- (3단계, ✅ 확정) 기습 성공자의 "원하는 카드 선택"은 엔진 기본값으로 최저 카드 자동 배정
  (UI 에서 선택권 제공 예정).
- (3단계, ✅ 확정) 방패 패리 스킬은 보유한 STR 기반 무기 스킬 중 최고 레벨을 자동 사용.
- (3단계, ✅ 확정) 크리티컬 doubleDice 와 암습 subtle +1주사위가 겹치면
  "기본 개수×2 + 1" 로 처리 ((개수+1)×2 아님).
- (3단계, ✅ 확정) NPC(미니언·일반)는 0 HP 에서 즉시 무력화(사망 처리) — 생존 여부는
  GM 재량이라는 원문을 1인 웹게임에서는 사망으로 고정. 보스 생존 연출은 추후 판단.
- (3단계, ✅ 확정) 근접 피해 완전 흡수 시 반사 피해의 내구도 검사에서 관통 예외를
  패리와 동일하게 적용하지 않음 — 원문이 패리에만 명시한 규칙이므로 반사는 유형 무관.
- (4단계, 잠정) 치명독 "제한 효과: 다음 턴 D6 한 번" 을 노출 시점 즉시 적용으로 근사.
- (4단계, 잠정) 스트레치 휴식의 능력 보정(깊은 명상류)은 옵션 파라미터로 주입 —
  6단계 능력 엔진에서 트리거를 정식화한다.
- (4단계, 잠정) "앓는 동안/굶주림/추위 회복 불가" 는 상태 플래그로 호출부(게임 루프)가
  휴식 함수 호출을 차단하는 방식. 엔진은 강제하지 않는다.
- (4단계, 잠정) 질병 발병 시점(패배 후 1일)의 시간 진행은 게임 루프 책임 —
  엔진은 판정과 발병 상태 전이만 제공.
- (5단계) 무기·방어구·아이템에 `metal` 필드 추가 (금속 제한 규칙의 데이터화).
- (5단계, 잠정) 일반 마법 시전 시 유파 스킬이 여럿이면 첫 유파 스킬 사용 —
  엔진 기본값 (최고 레벨 선택은 UI 에서).
- (5단계, 잠정) 용 시전의 3택1 효과(2배/무료/연쇄)는 게임 루프가 선택·적용.
  freeCast 의 WP 환급도 루프 책임.
- (5단계, 잠정) 사고표의 위력 비례 피해/WP 유출(7·8행)은 manual + extra 수치로 표기.
  → 6단계 applyMishapRow 가 자동 적용.
- (6단계) Ability 에 trigger 필드 추가 ('always' | 'stretchRest' | null) —
  패시브 능력의 적용 시점을 데이터화. 4단계 잠정 사항 해소.
- (6단계, 잠정) 'choice' 상태이상의 엔진 기본 선택 = 미보유 첫 항목 (UI 에서 선택권).
- (7단계, 잠정) 몬스터의 회피/패리 = 행동(카드) 1회 소모를 actionsLeft 카운터로 관리 —
  어느 카드를 뒤집을지는 낮은 카드부터로 게임 루프에서 처리.
- (7단계, 잠정) 유형 없는 피해(damageType null — 마법 등)는 물리 저항·면역을 우회.
- (7단계, 잠정) 몬스터 다리 4개 이상 여부는 데이터 필드가 아니라 호출 옵션 —
  베스티어리 확충 시 필드 승격 검토.
- (8단계, 잠정) 무기 파손 상태는 단일(사용 불가)로 관리 — 사고표의 "수리 전까지 베인"
  경상태는 UI/수동 처리. 필요 시 이중 상태로 승격.
- (9단계, 잠정) 여정 사고표의 개별 판정(곡예·회피 등)은 manual — 게임 루프가 진행.
  거리 배율(extra.distanceFactor)만 자동 반영.
- (10단계, 잠정) 도주 = 회피 판정 성공 시 전투 이탈 (원문 "EVADE 로 전투 이탈" 구체 절차
  미명시 — 실패 시 턴 소모로 처리).
- (10단계, 잠정) 몬스터 공격의 즉사 규칙(한 방 −최대HP)은 효과 훅 경로에서 미적용 —
  NPC 공격 경로에만 적용 (효과 훅은 초과 피해를 추적하지 않음). 훅 경로 즉사는 추후 승격.
  → (검수 단계) 0 HP 상태 추가 피해 = 죽음 판정 실패 +1 은 훅 경로에도 구현됨.
- (10단계, 잠정) 적 AI: 체력 절반 이하일 때만 리액션에 행동/턴을 소모.
- (UI 연결 단계, 잠정) 거리 모델: 적별 1차원 거리(m). 근접 간격 2m, long 무기 4m.
  공격 시 자유 이동으로 자동 접근하고, 이동력으로 못 닿으면 그 액션은 돌진(이동 ×2)이 된다.
  회피 성공 시의 2m 이동은 미적용.
- (UI 연결 단계) 원거리: 2m 이내 베인 / 유효 사거리 내 정상 / ×2까지 베인 / 그 밖 불가 (원문).
  투척 무기 사거리 = STR 또는 STR×2. 원거리 공격의 패리는 방패 필요 — 방패 뽑기 미구현이라
  현재는 회피만 가능.
- (UI 연결 단계) 기습: 무작위 조우는 주의력 판정 — 실패 시 적이 1라운드 카드를 고른다
  (최저 카드 근사, 원문 "victims get bottom cards"). PC 주도 개전(보스 입장)은 잠입 선택 →
  은신 판정(손에 원거리 수단이 없으면 접근 베인) — 성공 시 PC가 카드 선택 + 첫 공격 암습
  (보온·리액션 불가·subtle +1주사위), 실패 시 통상 개전.
- (UI 연결 단계) 대기: 뒤 순번·미행동 상대와 카드 교환 (상대는 거부 불가, 원문). 라운드 1회.
  교환 즉시 그 슬롯의 적이 행동한다.
- (UI 연결 단계, 잠정) 무장 해제: 성공 시 떨어진 무기(D6m)는 거리 미추적 — 적이 다음 턴에
  액션으로 줍는다. 무기가 전혀 없는 NPC는 간이 맨손 공격 (격투 판정, D6 타격).
- (UI 연결 단계) 붙잡기: 몬스터 불가 (원문). 실패 시 나만 넘어지고, 성공 시 둘 다 넘어지며
  상대는 벗어나기(격투 대결, 자유 행동)만 가능. 조르기 = 격투 보온, 회피·패리 불가,
  피해 D6+근력 보너스 (용이면 D6 2개 — 잠정). 상대가 쓰러지면 붙잡기 자동 해제.
- (UI 연결 단계) 과적: 소지 한도 초과 시 여정 시프트·전투 이동마다 근력 판정 (원문).
  실패 = 제자리 (짐 버리기는 인벤토리 수동 편집).
- (UI 연결 단계, 잠정) 준비 주문 교체(그리무아 필요, 한도 = INT 기본치)와 비전투 시전은
  저녁 활동 1회로 처리 (원문의 시프트/×2 시간 간이화). 그리무아 시전은 비전투 전용 —
  전투 중 2배 시간 시전은 미지원. 치유 주문만 자동 적용, 그 외는 효과 요약 로그.
- (UI 연결 단계) 무기 바꿔 들기 = 자유 행동, 라운드 1회 (원문 "one of each type per round").
- (UI 연결 단계, 잠정) NPC 이동력 = 10 고정 (데이터 필드 없음 — 필요 시 승격).
- (UI 연결 단계) 넘어진 참가자는 자기 턴 시작에 자유 행동으로 일어난다 (붙잡기 중 제외).
- (검수 단계, 버그 수정) 죽음 판정 3성공 회복이 combat.pc 에만 반영되고 character 에는
  반영되지 않아, 회복 직후 몬스터 공격이 HP 0 기준으로 계산되며 회복을 무효화하던
  문제 수정 (증상: "N 피해 (적용 0)" 후 즉시 재기절). 몬스터 효과는 이제 combat.pc HP 기준.
- (검수 단계) 밀쳐냄(knockback) 성공 시 해당 몬스터와의 거리가 밀려난 만큼 벌어진다.
- (검수 단계) 손에 무기가 전혀 없는 PC 는 맨손(unarmed 데이터)으로 자동 무장 —
  전투 개시 시 weaponsAtHand 폴백. 명중 버튼에 판정 스킬 이하값(≤N) 표시.
- (기제 점검) 약점·기념품 표(D20×2, 내용 공란) 신설 + 생성 화면 D20 굴림/재굴림 연결.
  기념품 실기제: 스트레치 휴식 시 상태이상 1개 추가 회복 — 원문 "게임 세션당 1회"를
  모험당 1회로 잠정 처리. 약점의 기제는 기존 정산 질문("약점에 굴복했는가")이 담당.
- (훅 승격 1·2군) 소지품 연결: 지도→길찾기, 텐트→야영(usingTent), 장화·망토→여정 사고,
  모피 외투→폭우 추위 판정(CON, 망토 있으면 면제), 낚싯대/그물→낚시(저녁 행동 신설),
  올가미/곰덫→덫 사냥 자격, 화살통→사격 자격(목제뿐이면 상대 방어구 ×2), 배낭(기구현).
  사나운 짐승·멧돼지 역습은 animals.json 실스탯 전투로 교체(자연 무기 = 일반 스킬 판정,
  회피·패리 가능) — 사냥감 승리 시 사냥감표 수확 획득.
- (훅 승격 1·2군) 돌풍·해일·회오리·정신 타격 → knockback 훅 (전투 시전 시 피해+거리+넘어짐
  자동, 위력당 주사위 +1). 전투 함성 → healCondition. action 발동 능력은 턴을 소모한다.
- (훅 승격 3군) 신규 훅: immuneFear(공포 자동 저항), parryRangedWithMelee(화살 쳐내기),
  ignoreLongRangeBane(독수리 눈 — 원문 1스트레치 발동을 상시 패시브로 잠정 간이화),
  throwAnyMelee(던지기 팔 — 던진 무기 낙하는 미적용 잠정), reduceFallDamage(엔진만 — 낙하
  이벤트 미노출), autoActivity(야영 자동 성공 — 외로운 늑대는 1인 기준 병참 장교와 동치 잠정),
  lifeDrain(흡혈), selfHit/dropWeapon/outOfAmmo(전투 사고표 구조화 — PC 무기 줍기 액션 추가,
  NPC 도 대실패 시 무기 낙하). 화살 소진은 이번 전투 동안 지속.
- (훅 승격 3군) 중상표 연결: 죽음 판정 3성공 회복 시 체력 판정 — 실패하면 중상 굴림.
  영구 스킬 페널티(extra.skillPenalty)와 새 약점(성격 변화)은 자동 적용, 치유 기간이 있는
  일시 항목은 규칙 요약 로그로 수동 처리 (기간 추적 시스템은 미구현 — 잠정).
- (검수 단계) 실플레이 캡처 하네스 scripts/capture.mjs — 술사/무인/좁은 화면 3시나리오를
  실클릭으로 주파하며 스크린샷·콘솔 오류 수집.
- (10단계, 임시 수치) 1인 플레이 기준으로 수호자(stonehide) 하향(HP 30·방어 2·주사위 한 단계).
